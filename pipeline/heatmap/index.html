    Stage 5 — Heatmap Generation (3DHeatMap.py)

    3DHeatMap.py reads the raw RSS grid from heatmap.csv, applies Gaussian smoothing, renders it on an OpenStreetMap basemap, and packages everything as a KMZ file for Google Earth.

    Run

    python3 bin/3DHeatMap.py \
  --csv heatmap.csv \
  --topology_csv topology.csv \
  --outdir outputs \
  --out_prefix my_coverage

    Inputs

    File Format Description
    heatmap.csv CSV X, Y (EPSG:3857), RSS (dBm) from prop
    topology.csv CSV Antenna positions and azimuths for arrow overlay

    Processing steps

    flowchart TD
    A[Read heatmap.csv] --> B[Clean invalid rows]
    B --> C[Aggregate XY points into grid cells]
    C --> D[Gaussian smoothing sigma]
    D --> E[Mask cells below min_weight threshold]
    E --> F[Render on OSM basemap with contextily]
    F --> G[Export PNG with colorbar]
    G --> H[Export transparent PNG overlay]
    H --> I[Export GeoTIFF in EPSG:3857]
    I --> J[Compute antenna arrow geometry from azimuth]
    J --> K[Write KML with GroundOverlay and ScreenOverlay]
    K --> L[Package into KMZ]

    Outputs

    File Description
    <prefix>.png 2D heatmap rendered on OpenStreetMap
    <prefix>_transparent.png Heatmap with transparent background
    <prefix>.tif Coloured GeoTIFF in EPSG:3857
    <prefix>_legend.png Colour scale legend image
    <prefix>_overlay.png Overlay PNG for KML GroundOverlay
    <prefix>.kml KML file with all overlays and antenna arrows
    <prefix>.kmz Compressed Google Earth package (open this)

    Command line arguments

    Input arguments

    Argument Default Description
    --csv heatmap1.csv Path to RSS grid CSV
    --x X Column name for projected X
    --y Y Column name for projected Y
    --rsrp RSS Column name for signal values
    --topology_csv topology.csv Antenna topology file

    Heatmap tuning

    Argument Default Description
    --cell 1.0 Grid cell size in metres
    --sigma 5.0 Gaussian blur strength in grid cells
    --min_weight 0.02 Mask threshold after blurring
    --alpha 0.60 Heatmap transparency on 2D OSM plot
    --cmap turbo Matplotlib colourmap

    Antenna arrows

    Argument Default Description
    --antenna_length_m 120 Arrow length in metres
    --arrow_head_m 25 Arrowhead size in metres
    --arrow_head_angle_deg 25 Arrowhead opening angle
    --antenna_line_width 5 Arrow line thickness in Google Earth
    --antenna_label_scale 2.0 Label text size in Google Earth

    Output

    Argument Default Description
    --outdir outputs Output directory
    --out_prefix rsrp0_dummy Filename prefix for all outputs

    Opening in Google Earth

    File → Open → select outputs/<prefix>.kmz

    File → Open → select outputs/<prefix>.kml or .kmz

    The heatmap will drape over terrain. The legend appears as a screen overlay. Antenna direction arrows are vector overlays scaled in metres.

    Colour scale

    The heatmap uses a fixed RSRP scale:

    Colour RSS range Meaning
    Red / yellow -60 to -75 dBm Strong signal
    Green -75 to -95 dBm Usable signal
    Blue / purple -95 to -120 dBm Weak signal
    Transparent below -120 dBm No coverage
