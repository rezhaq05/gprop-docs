    Stage 1 — GUI (gui.py)

    gui.py is the entry point of the pipeline. It starts a local Flask web server and opens a browser-based map editor where you draw the area of interest and place antenna base stations.

    Run

    python3 bin/gui.py

    A browser opens at http://127.0.0.1:5000. When finished, press ENTER in the terminal.

    Inputs

    None — this is the first stage. All data is entered interactively in the browser.

    What you do in the browser

    flowchart LR
    A[Open geojson_creator.html] --> B[Draw AoI polygon]
    B --> C[Place antenna markers]
    C --> D[Fill in antenna properties]
    D --> E[Click Save]
    E --> F[Press ENTER in terminal]

    Antenna properties per marker:

    Field Unit Description
    azimuth degrees Horizontal pointing direction, 0 = North
    frequency MHz Carrier frequency
    Ptx (power) dBm Transmit power
    Gtx (gain) dBi Antenna boresight gain
    height m Height above ground

    Outputs

    File Format Description
    scenario.geojson GeoJSON Raw drawn features — polygon + point markers
    aoi.wkt Plain text First feature (polygon) as WKT in EPSG:4326, one line
    topology.csv CSV One antenna per line, 8 columns, no header

    aoi.wkt format

    POLYGON ((-78.875 42.895, -78.855 42.895, -78.855 42.915, -78.875 42.915, -78.875 42.895))

    topology.csv format

    lon,lat,height_m,azimuth_deg,downtilt_deg,freq_MHz,power_dBm,gain_dBi
-78.8645,42.9067,20.0,90.0,-1.0,3560.0,43.0,17.0
-78.8650,42.9070,18.0,180.0,-1.0,3640.0,43.0,17.0

    Downtilt

    Downtilt is hardcoded to -1.0 in the GUI. Edit topology.csv directly after saving if you need a specific mechanical downtilt value.

    Routes

    Route Method Description
    / GET Serves geojson_creator.html
    /custom_scenario GET Serves scenario_customizer.html
    /save_geojson POST Saves scenario and writes aoi.wkt + topology.csv
    /save_custom_scenario POST Saves virtual antenna overlay
    /get_current_scenario GET Returns current scenario.geojson contents
    /shutdown POST Gracefully stops the Flask server
