    Stage 4 — Propagation (prop)

    prop is a compiled C binary that computes received signal strength (RSS) at every 5m grid point inside the area of interest. It loads the digital twin produced by preproc and models signal propagation using free-space path loss and multi-knife-edge diffraction.

    Run

    # single-threaded
./bin/prop topology.csv antenna.pat aoi.wkt buildings.csv trees.csv ground.tif

# multi-threaded (recommended)
OMP_NUM_THREADS=8 ./bin/prop topology.csv antenna.pat aoi.wkt buildings.csv trees.csv ground.tif

    Inputs

    Argument File Format Description
    argv[1] topology.csv CSV Antenna parameters, 8 columns, no header
    argv[2] antenna.pat Plain text 541 dB attenuation values, one per line
    argv[3] aoi.wkt Plain text Area of interest polygon in EPSG:4326
    argv[4] buildings.csv CSV Roof plane equations from preproc
    argv[5] trees.csv CSV Tree cluster data from preproc
    argv[6] ground.tif GeoTIFF 1m bare-earth DSM

    topology.csv column order

    lon, lat, height_above_ground_m, azimuth_deg, downtilt_deg, freq_MHz, power_dBm, gain_dBi

    -78.8645,42.9067,20.0,90.0,-1.0,3560.0,43.0,17.0

    antenna.pat format

    541 lines total. No header. One dB attenuation value per line.

    Lines 1–360    → horizontal pattern, degrees 0–359
                 0.0 dB at boresight, negative values = attenuation
Lines 361–541  → vertical pattern, degrees 0–180
                 line 361+90 = 451 is horizontal boresight (0.0 dB)

    Processing steps

    flowchart TD
    A[Read topology.csv] --> B[Project lat/lon to EPSG:3857 via PROJ]
    B --> C[Read antenna.pat]
    C --> D[init_twin: load buildings.csv and trees.csv]
    D --> E[Build 10m tile grid with Amanatides-Woo traversal]
    E --> F[Read ground.tif DSM]
    F --> G[For every 5m grid point inside AoI polygon]
    G --> H[ground_elevation lookup from DSM]
    H --> I[Set RX height = ground + 2m]
    I --> J[diffraction_loss: build LOS profile]
    J --> K[Intersect LOS with building and tree footprint edges]
    K --> L[Prune dominated edges]
    L --> M[Fresnel-Kirchhoff knife-edge loss per hop]
    M --> N[base_loss: FSPL + antenna gain from pattern]
    N --> O[RSS = power - diffraction_loss - base_loss]
    O --> P[Keep max RSS across all Tx]
    P --> Q[Write to heatmap.csv]
    G --> G

    Outputs

    File Format Description
    heatmap.csv CSV X (EPSG:3857), Y (EPSG:3857), RSS (dBm) per grid point

    heatmap.csv format

    -8771523.6917,5309832.0847,-86.52
-8770820.0812,5309991.3873,-68.72

    Key parameters (hardcoded in prop.c)

    Parameter Value Description
    HEATMAP_RESOLUTION 5 m Grid spacing
    RX_HAG 2 m Receiver height above ground
    SCALE 10 m Tile size for spatial indexing
    INITIAL_PROFILE_LEN 1000 Initial edge buffer for diffraction

    Performance

    Cores Mean runtime
    1 22,317 ms
    2 11,548 ms
    4 6,112 ms
    8 4,542 ms
    10 4,061 ms

    Set OMP_NUM_THREADS to control thread count. Optimal is 4–8 for this workload — scaling becomes sub-linear above 8 due to memory bandwidth.
