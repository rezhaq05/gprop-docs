    Pipeline Overview

    gprop is organised as five sequential stages. Each stage produces files consumed by the next. Stages 3 and 4 (preproc and prop) are pre-compiled C binaries; the rest are Python scripts.

    Full data flow

    flowchart TD
    subgraph stage1["Stage 1 — gui.py"]
        G1[Draw AoI polygon]
        G2[Place antenna markers]
        G3[Set azimuth / freq / power / gain / height]
        G1 --> G2 --> G3
    end

    subgraph stage2["Stage 2 — fetch.py"]
        F1[Query USGS 3DEP LiDAR]
        F2[Query OSM Overpass API]
        F3[Generate bare-earth DSM]
        F1 --> F3
        F2 --> F3
    end

    subgraph stage3["Stage 3 — preproc (C binary)"]
        P1[Read LAZ point cloud]
        P2[Assign points to building footprints]
        P3[RANSAC plane segmentation]
        P4[Euclidean tree clustering]
        P1 --> P2 --> P3
        P1 --> P2 --> P4
    end

    subgraph stage4["Stage 4 — prop (C binary)"]
        R1[Load digital twin into tile grid]
        R2[For each 5m grid point inside AoI]
        R3[Compute diffraction loss along LOS]
        R4[Compute FSPL and antenna gain]
        R5[Write best RSS across all Tx]
        R1 --> R2 --> R3 --> R4 --> R5
    end

    subgraph stage5["Stage 5 — 3DHeatMap.py"]
        H1[Read heatmap.csv]
        H2[Gaussian smoothing]
        H3[Render on OSM basemap]
        H4[Export KML/KMZ]
        H1 --> H2 --> H3 --> H4
    end

    stage1 -->|"aoi.wkt, topology.csv"| stage2
    stage2 -->|"lpc.laz, buildings.wkt, ground.tif"| stage3
    stage3 -->|"buildings.csv, trees.csv"| stage4
    stage4 -->|"heatmap.csv"| stage5

    File summary

    File Producer Consumer Description
    aoi.wkt gui.py prop, fetch.py Area of interest polygon in EPSG:4326
    topology.csv gui.py prop Antenna parameters, one per line
    lpc.laz fetch.py preproc LiDAR point cloud, non-ground filtered
    buildings.wkt fetch.py preproc OSM footprints, one WKT polygon per line
    ground.tif fetch.py preproc, prop 1m bare-earth DSM GeoTIFF
    buildings.csv preproc prop Roof plane equations and footprints
    trees.csv preproc prop Tree cluster footprints and heights
    heatmap.csv prop 3DHeatMap.py X, Y, RSS per 5m grid point
    outputs/*.kmz 3DHeatMap.py Google Earth Final coverage heatmap overlay
