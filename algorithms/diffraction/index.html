    Knife-Edge Diffraction

    prop models signal attenuation through urban obstacles using the Fresnel-Kirchhoff knife-edge diffraction model applied sequentially across the dominant edges along each line-of-sight path.

    Profile construction

    For each transmitter-receiver pair, populate_profile in diffraction.c:

    1. Uses Amanatides-Woo grid traversal to find all 10m tiles along the LOS
    2. For each tile, computes the minimum LOS elevation at the tile boundary
    3. Skips tiles where max_elev < min_los_elev (early exit)
    4. For surviving tiles, intersects the LOS segment against every building and tree footprint edge using 2D determinant intersection
    5. Each intersection point becomes an Edge with:
      • distance — 3D distance from transmitter to intersection point
      • elev — obstacle height above the LOS line (negative values discarded)

    Profile reduction

    process_profile retains only the convex hull of obstructions visible from the transmitter — edges dominated by a taller closer edge are pruned.

    Loss computation

    For each retained edge the Fresnel-Kirchhoff diffraction parameter v is computed:

    $$v = h \sqrt{\frac{2}{\lambda} \left(\frac{1}{d_1} + \frac{1}{d_2}\right)}$$

    Where:

    Symbol Meaning
    h Edge height above the LOS line between the two flanking points
    λ Wavelength (c / frequency)
    d₁ Distance from transmitter to the edge
    d₂ Distance from edge to receiver

    The ITU-R approximation gives loss in dB:

    $$L = 6.9 + 20 \log_{10}\left(\sqrt{(v - 0.1)^2 + 1} + v - 0.1\right) \quad \text{for } v > -0.78$$

    $$L = 0 \text{ dB} \quad \text{for } v \leq -0.78 \text{ (clear LOS)}$$

    Multi-edge cascade

    For multiple dominant edges, loss is accumulated hop by hop — a Deygout-style sequential cascade:

    TX ──── edge₁ ──── edge₂ ──── ... ──── RX
        hop₁        hop₂
L_total = hop_loss(TX, edge₁, edge₂)
        + hop_loss(edge₁, edge₂, edge₃)
        + ...
        + hop_loss(edgeₙ₋₁, edgeₙ, RX)

    Parameters

    Parameter Value Description
    PROFILE_EXT 100 Edge buffer growth step
    INITIAL_PROFILE_LEN 1000 Initial edge buffer allocation
    SCALE 10 m Tile size for grid traversal
