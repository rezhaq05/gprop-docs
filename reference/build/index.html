    Build System

    gprop uses a two-level POSIX Makefile system. The root Makefile dispatches to sub-Makefiles in preproc/ and prop/ with platform-specific variables.

    Build commands

    make TARGET=darwin

    make TARGET=linux

    make TARGET=windows

    Binaries are written to bin/preproc and bin/prop.

    Dependencies

    brew install pdal gdal geos proj gcc make

    apt install libpdal-dev libgdal-dev libgeos-dev libproj-dev gcc g++ make

    conda install -c conda-forge pdal gdal geos proj -y

    Root Makefile variable reference

    Variable Description
    CC C compiler
    CXX C++ compiler
    LD Linker
    CFLAGS C compile flags
    CXXFLAGS C++ compile flags
    LDFLAGS Linker flags including -lpdal, -lgdal, -lgeos_c, -lproj
    PREPROC_OUT Output path for preproc binary
    PROP_OUT Output path for prop binary
    OBJ_OUT Object file output flag (-o or /Fo on MSVC)
    EXE_OUT Executable output flag

    Source files

    preproc

    File Language Role
    preproc/preproc.c C99 Entry point, DSM/footprint I/O
    preproc/segmentation.c C99 RANSAC, region growing, clustering
    preproc/data-structures.c C99 KD-tree and binary search tree
    preproc/lazio.cc C++17 PDAL bridge for LAZ I/O
    preproc/ply.c C99 PLY mesh generation

    prop

    File Language Role
    prop/prop.c C99 Entry point, path loss models, heatmap loop
    prop/twin.c C99 Digital twin loading and tile grid
    prop/diffraction.c C99 Knife-edge diffraction profile and loss
