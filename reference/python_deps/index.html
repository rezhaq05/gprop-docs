    Python Dependencies

    All Python dependencies needed to run fetch.py, gui.py, and 3DHeatMap.py.

    Install everything at once

    pip install flask requests geopandas shapely overpy pdal rasterio contextily pyproj scipy pandas matplotlib werkzeug

    Per-script breakdown

    fetch.py

    Package Version Why it's needed
    requests any Downloads the USGS resources.geojson project index from GitHub
    geopandas ≥ 0.13 Reads the GeoJSON project boundaries, reprojects building footprints from EPSG:4326 to EPSG:3857
    shapely ≥ 2.0 WKT parsing, polygon intersection checks, geometry construction
    overpy any Queries the OpenStreetMap Overpass API for building footprints
    pdal ≥ 2.5 Reads and writes LAZ/LAS files, runs the EPT reader pipeline against the USGS S3 bucket, generates the DSM via writers.gdal 
    pip install requests geopandas shapely overpy pdal

    PDAL on macOS

    PDAL has a compiled C++ extension. If pip install pdal fails, install via Homebrew first: 

    brew install pdal
pip install pdal

    PDAL on Windows

    Use conda instead of pip: 

    conda install -c conda-forge pdal -y

    gui.py

    Package Version Why it's needed
    flask ≥ 2.0 Web server that serves the map editor and handles save/load routes
    werkzeug ≥ 2.0 Used by Flask internally; also used directly for make_server to enable clean shutdown
    requests any Sends the POST /shutdown request from Python to stop the Flask server
    geopandas ≥ 0.13 Reads scenario.geojson and extracts the AoI polygon and antenna points
    pandas ≥ 1.5 Used by geopandas internally; also used in the /coverage_data route to read best_data.csv 
    pip install flask werkzeug requests geopandas pandas

    3DHeatMap.py

    Package Version Why it's needed
    numpy ≥ 1.23 Grid construction, Gaussian smoothing input arrays
    pandas ≥ 1.5 Reads heatmap.csv and topology.csv
    matplotlib ≥ 3.6 Renders the heatmap, colourbar legend, and 2D OSM plot
    scipy ≥ 1.9 gaussian_filter for heatmap smoothing
    pyproj ≥ 3.4 Reprojects antenna lat/lon from EPSG:4326 to EPSG:3857 for arrow placement
    rasterio ≥ 1.3 Writes the coloured GeoTIFF output
    contextily ≥ 1.3 Downloads and tiles the OpenStreetMap basemap for the 2D plot 
    pip install numpy pandas matplotlib scipy pyproj rasterio contextily

    numpy

    numpy is a dependency of pandas, scipy, rasterio, and matplotlib — it will be installed automatically. You do not need to install it separately.

    Full install (all three scripts)

    pip install \
  flask \
  werkzeug \
  requests \
  geopandas \
  shapely \
  overpy \
  pdal \
  pandas \
  numpy \
  matplotlib \
  scipy \
  pyproj \
  rasterio \
  contextily

    Verify your install

    Run this to confirm every package imports correctly:

    python3 -c "
import flask, werkzeug, requests
import geopandas, shapely, overpy, pdal
import pandas, numpy, matplotlib, scipy
import pyproj, rasterio, contextily
print('All packages OK')
"

    Python version

    Python 3.9 or later is required. Check yours:

    python3 --version

    brew install python3

    sudo apt install python3 python3-pip

    Download from python.org or use conda: 

    conda install python=3.11

    Virtual environment (recommended)

    Keeps gprop dependencies isolated from your system Python:

    # create
python3 -m venv gprop_env

# activate — macOS / Linux
source gprop_env/bin/activate

# activate — Windows
gprop_env\Scripts\activate

# install everything
pip install flask werkzeug requests geopandas shapely overpy pdal \
            pandas numpy matplotlib scipy pyproj rasterio contextily

# deactivate when done
deactivate
