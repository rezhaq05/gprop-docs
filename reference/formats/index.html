    File Formats

    Complete specification of every file in the gprop pipeline.

    aoi.wkt

    Plain text, single line, WKT polygon in EPSG:4326 (longitude/latitude).

    POLYGON ((-78.875 42.895, -78.855 42.895, -78.855 42.915, -78.875 42.915, -78.875 42.895))
    • First coordinate = last coordinate (closed ring)
    • Longitude first, latitude second
    • Written by gui.py, read by fetch.py and prop

    topology.csv

    CSV, no header, 8 columns per line.

    lon,lat,height_m,azimuth_deg,downtilt_deg,freq_MHz,power_dBm,gain_dBi
-78.8645,42.9067,20.0,90.0,-1.0,3560.0,43.0,17.0
    Column Type Unit Description
    lon float degrees Antenna longitude
    lat float degrees Antenna latitude
    height float m Height above ground level
    azimuth float degrees Horizontal pointing, 0 = North
    downtilt float degrees Mechanical downtilt, negative = downward
    freq float MHz Carrier frequency
    power float dBm Transmit power
    gain float dBi Boresight antenna gain

    antenna.pat

    Plain text, 541 lines, one dB attenuation value per line. No header.

    Lines 1–360    horizontal pattern (degrees 0–359)
Lines 361–541  vertical pattern (degrees 0–180)
    • Values are attenuation relative to boresight (negative or zero)
    • 0.0 dB = boresight direction, maximum gain
    • -25.0 dB = 25 dB below boresight

    buildings.wkt

    Plain text, one WKT polygon per line, EPSG:3857.

    POLYGON ((748232.1 6421847.3, 748250.4 6421847.3, ...))
    • Written by fetch.py from OSM data
    • Easting/northing in metres (web Mercator)

    buildings.csv

    CSV written by preproc. One roof plane facet per line.

    "POLYGON ((x1 y1, x2 y2, ...))",a,b,c,d
    Field Description
    WKT (quoted) 2D footprint of the roof plane in EPSG:3857
    a, b, c Normal vector components of the roof plane
    d Plane offset — elevation at point (x,y) = (d − ax − by) / c

    trees.csv

    CSV written by preproc. One tree cluster per line.

    "POLYGON ((x1 y1, x2 y2, ...))",max_elevation
    Field Description
    WKT (quoted) 2D footprint of the tree cluster crown in EPSG:3857
    max_elevation Highest point in the cluster, metres above sea level

    ground.tif

    GeoTIFF, single Float64 band, EPSG:3857, 1m resolution.

    • Values: elevation in metres above sea level
    • Holes (NoData) filled by gdal_fillnodata
    • Written by fetch.py, read by preproc and prop

    heatmap.csv

    CSV written by prop. Three columns, no header.

    x_epsg3857,y_epsg3857,rss_dbm
-8771523.6917,5309832.0847,-86.52
    Column Unit Description
    X metres Easting in EPSG:3857
    Y metres Northing in EPSG:3857
    RSS dBm Best received signal strength across all transmitters
    • Grid spacing: 5m
    • Only points inside aoi.wkt are included
    • RSS = transmit power − free-space path loss − diffraction loss + antenna gain
